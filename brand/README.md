# Логотип «Елена Новак»

Знак — монограмма «ЕН» в скруглённом квадрате с засечкой на нижней грани,
вордмарк — Playfair Display 600. Текст переведён в кривые: файлы выглядят
одинаково везде, шрифт устанавливать не нужно.

| Файл | Где применять |
| --- | --- |
| `logo-full.svg` | основной: тёмный фон (сайт, презентации на near-black) |
| `logo-full-light.svg` | светлый фон: бланки, договоры, печать на белом |
| `logo-full-mono.svg` | один цвет через `currentColor` (или `fill` у `<svg>`): факсимиле, штампы, ч/б печать |
| `logo-mark.svg` | только знак: аватар в мессенджерах, соцсети, водяной знак |
| `favicon.svg` | иконка вкладки, знак на фирменном фоне с полем |

## Правила

- Минимальная ширина полного логотипа — **120 px** (ниже монограмма
  замыливается, используйте `logo-mark.svg`).
- Охранное поле вокруг — не меньше высоты знака (40 px в масштабе 1:1).
- Не растягивайте непропорционально, не меняйте расстояние между знаком
  и вордмарком, не подставляйте другой шрифт.

## Цвета

| Токен | HEX | Назначение |
| --- | --- | --- |
| Gold | `#C4A05A` | знак, монограмма, засечка |
| Ink | `#EDEAE3` | вордмарк на тёмном |
| Near-black | `#0B0B0D` | вордмарк на светлом, фон фавикона |
